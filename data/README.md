# Generated data

`dashboard.json` is generated by `scripts/update_attack.py` from the latest MITRE ATT&CK Enterprise STIX 2.1 dataset.

v0.2 adds reverse relationships required by the cross-entity explorer:

- Actor ⇄ Technique
- Actor ⇄ Software
- Actor ⇄ Campaign
- Software ⇄ Technique
- Software ⇄ Campaign
- Technique ⇄ Campaign

`meta.schema_version` is `0.2.0` for data generated by the v0.2 updater.

Do not hand-edit generated records. The placeholder file in a fresh checkout is replaced before deployment.
