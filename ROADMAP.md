# Threat Investigation Roadmap

v1.0 freezes the core investigation model. Future work should extend the platform without weakening the evidence boundary.

## v1.1+ candidates

- Current Intelligence / world-event-aware Quick Start supplied by Security Intelligence Library
- richer Navigation Context cards from Library articles
- Campaign enrichment from additional public CTI sources, kept separate from ATT&CK-native evidence
- saved investigations / shareable investigation state
- optional comparison of two entities
- improved Platform investigation views
- accessibility and mobile-density refinement

## Deliberately out of v1.0

- risk scoring
- automatic Actor → CVE attribution
- inferred Actor relationships from shared Techniques
- vulnerability prioritization inside Threat Investigation
- news aggregation inside Threat Investigation
- organization-specific attack likelihood claims

These belong to other platform layers or require stronger evidence than the current ATT&CK-native model provides.
